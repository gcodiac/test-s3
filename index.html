The platform

          
Everything a small site needs, nothing it doesn't

          

            Each capability below maps to a real AWS resource in infra/ and a real
            step in the delivery pipeline. Nothing here is decorative.
          

        


        

          

            
            
Private origin, public site

            
The bucket blocks all public access. Only the CloudFront distribution can read objects, authorised by an Origin Access Control signature on every request.

            
aws_s3_bucket_public_access_block

          


          

            
            
Global edge delivery

            
Content is cached at hundreds of points of presence, compressed with Brotli or gzip, and served from the location closest to the visitor.

            
aws_cloudfront_distribution

          


          

            
            
TLS without renewals

            
Certificates are issued and rotated by AWS Certificate Manager. HTTP is redirected to HTTPS at the edge, so plaintext never reaches the origin.

            
aws_acm_certificate

          


          

            
            
Infrastructure as code

            
Buckets, distributions, policies and roles are declared in Terraform. The plan is reviewed in a pull request before anything reaches the account.

            
terraform plan · terraform apply

          


          

            
            
Keyless deployments

            
GitHub Actions exchanges a short-lived OIDC token for an IAM role. No long-lived AWS access keys are ever stored as repository secrets.

            
sts:AssumeRoleWithWebIdentity

          


          

            
            
Verified releases

            
After each deploy the pipeline invalidates the cache and re-requests the site, asserting the live build identifier matches the commit that triggered it.

            
scripts/verify-deployment.sh

Architecture

          
One request path, locked down end to end

          

            The bucket has no website endpoint and no public policy. It is reachable only through
            CloudFront, which signs each origin request with its Origin Access Control identity.
          

          

            

              
 Viewer → CloudFront

              
DNS resolves to the nearest edge location. HTTP is redirected to HTTPS; the response is compressed and cached.

            

            

              
 CloudFront → S3

              
On a cache miss the edge calls the bucket's REST endpoint using SigV4 credentials from its Origin Access Control.

            

            

              
 Bucket policy

              
Access is granted to the CloudFront service principal, and only when the source ARN matches this exact distribution.
